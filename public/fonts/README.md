# Fonts

FMRXR fonts are loaded by `next/font/google` in `src/app/layout.tsx`, nothing to self-host here:

- **Geist**: titles (`.fm-display`, weight 900, capitals, -0.03em) and UI
- **Space Grotesk**: running text (`.fm`, `.fm-grotesk`)
- **Geist Mono**: labels, data, indexes

Monument Extended and Resolve Sans are the **EXPLAB** collective's fonts, not FMRXR's.
They were declared here once but never installed; removed on 09/10/2026.
